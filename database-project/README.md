# Stock Compass — 기업 투자 리서치 및 가상 포트폴리오 관리 서비스

> 기업의 재무·시장·이벤트 정보를 한곳에서 비교하고, 관심 기업·가상 거래·투자 가설을 기록하여 투자 판단 과정을 관리하는 웹 서비스

## 프로젝트 상태

현재는 **1차: 프로젝트 초안** 단계입니다. 이 단계에서는 서비스 문제 정의, 사용자, 핵심 기능, 예상 데이터 구조와 구현 계획을 정리했습니다.

| 단계 | 산출물 | 상태 |
| --- | --- | --- |
| 01_proposal | 프로젝트 기획서, 발표 구성, 예상 질의응답 | 완료 |
| 02_refinement | 화면 설계, 요구사항, ERD 초안 | 예정 |
| 03_analysis-design | 최종 ERD, 테이블 명세, SQL, 정규화 근거 | 예정 |
| 04_final | DB 연동 웹 애플리케이션, 시연 자료 | 예정 |

## 핵심 원칙

- 이 서비스는 종목 매수·매도를 추천하지 않으며, 사용자의 투자 판단을 위한 **정보 정리 및 기록 도구**다.
- 생성형 AI는 기업 정보와 사용자가 저장한 데이터를 요약하는 보조 수단으로 사용한다. 기업·거래·재무 데이터의 기준 데이터는 관계형 데이터베이스가 관리한다.
- 실제 금융 데이터 API 연동 여부와 무관하게, 시연 가능한 공개·샘플 데이터를 구성하여 안정적으로 동작하도록 한다.
