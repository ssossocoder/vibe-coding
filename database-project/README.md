# Stock Compass — 기업 투자 리서치 및 가상 포트폴리오 관리 서비스

> 기업의 재무·시장·이벤트 정보를 한곳에서 비교하고, 관심 기업·가상 거래·투자 가설을 기록하여 투자 판단 과정을 관리하는 웹 서비스

## 1차 기획안 제출 파일

- [프로젝트 기획서](01_proposal/proposal.md)

이 기획서에는 프로젝트 목적, 비즈니스 모델, 문제 정의, 주요 사용자와 기능, 예상 테이블·관계, 데이터베이스 수업 개념 적용 계획, 향후 구현 계획을 담았다.

| 핵심 기능 | 기업 검색·비교, 관심목록, 가상 포트폴리오, 거래 기록, 투자 가설·메모 관리 |

| 구현 범위 | 실제 주문·투자 추천 없이, 샘플 데이터를 기반으로 CRUD·검색·비교·집계 기능 구현 |

## 발표 시 설명 순서

1. 개인 투자자의 정보 분산과 판단 기록 문제를 설명한다.
2. 기업 검색 → 비교 → 관심목록 → 가상 거래/가설 → 결과 복기 흐름을 소개한다.
3. 기업 데이터와 사용자 활동 데이터를 어떻게 PK/FK, 1:N, N:M 관계로 연결하는지 설명한다.
4. 2차 화면·ERD 초안, 3차 SQL·스키마, 4차 웹 애플리케이션 구현 계획을 제시한다.

## 핵심 원칙

- 이 서비스는 종목 매수·매도를 추천하지 않으며, 사용자의 투자 판단을 위한 **정보 정리 및 기록 도구**다.
- 생성형 AI는 기업 정보와 사용자가 저장한 데이터를 요약하는 보조 수단으로 사용한다. 기업·거래·재무 데이터의 기준 데이터는 관계형 데이터베이스가 관리한다.
- 실제 금융 데이터 API 연동 여부와 무관하게, 시연 가능한 공개·샘플 데이터를 구성하여 안정적으로 동작하도록 한다.
